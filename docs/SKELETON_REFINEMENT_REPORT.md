## 4. 共通エンジン・左右・描画順

共通の投影、リグ、キャッシュ、Renderer、CharacterView、描画プリミティブ、公開APIは変更していません。`src/` 内の変更は内蔵骸骨のファイルだけです。他の28ファイルは既存ハッシュ基準と一致し、剣士・弓使い・重装戦士の造形も変更していません。旧 `drawSkeleton(ctx,x,y,t,scale)` および描画補助関数のexportは維持しました。

コードから確認できる仕組み:

- 既存 `rigFrame` の座標系（a=前、b=本人の左、z=上）を使用し、寸法は骸骨独自。人間用の脚・頭寸法は流用しません。
- 右腕はb<0、左腕はb>0。剣は常に `handR`、盾は常に `handL` に取り付けます。肩当て・すね当ても左側に固定。
- 奥の脚→手前の脚→骨盤、上半身は奥の腕と装備→肋骨→手前の腕と装備→頭の順。NW/SWでは右腕が奥、NE/SEでは左腕が奥。頭を隠す位置まで剣を振らない待機姿勢です。
- 頭部の正面/背面部品だけ `sx` を使い横向きを表現。全身や装備を反転しません。背面では眼窩を描かず、後頭部の縫合線、背骨、盾の裏板と腕帯を描きます。
- 足は共通 `footProj` で地面に固定。上半身・腕・剣・盾を腰の周りで一体に回転させ、骨を伸縮させません。顎は重なりを保つ0.45px以内の動き。
- 部品ごとのseedは時刻に依存しません。骸骨ではlineBoil有効時も点描の再抽選を行いません。
- キャッシュは既存機構の定義オブジェクト・倍率・描画設定による更新を利用。再登録時の旧フレーム解放も検査しました。

### 計測と制作ルール

頭身は、羽飾り・武器・盾・影を除く「頭頂〜足裏 ÷ 頭頂〜顎」で概算します。兜は頭に沿う本体を含めます。SE、idle、位相0、倍率1を基準とし、frameBoxの余白は含めません。

コード上の衛士の頭中心はz=66、頭の描画倍率0.9、兜頂点y=-29、顎y=18なので、頭の高さは `(29+18)*0.9=42.3px`。SE投影後の頭頂yは約-91.8です。足の投影・輪郭を含む全高はおよそ98px、約2.3頭身です。添付画像の目視でも約2.2〜2.3頭身と読めます。塗りの曲線・ペンの揺れ・足の奥行きで数px変わるため、厳密な人体計測ではありません。

`docs/STUDIO_GUIDE.md` に約2.2頭身（目安2.1〜2.3）、頭高42〜45px、頭頂まで90〜94pxという制作基準と計測方法を追加し、制作AIへの指示テンプレートにも組み込みました。`docs/CHARACTER_GUIDE.md` とREADMEからも参照できます。既存の他キャラを自動的に変更するルールではありません。
