# 部屋ガイド

## 1. 部屋データの定義

部屋は「矩形の床 + 奥の2面の壁 (左奥 x=0・右奥 y=0) + 手前の縁石」です。すべてデータで指定します。

```js
renderer.setRoom({
  id: 'crypt-1',                 // 石組み・床のひびの乱数の種 (同じ id なら毎回同じ見た目)
  width: 6, depth: 6,            // 床のマス数
  wallHeight: 3.24,              // 壁の高さ (1 = 66px)。石積み1段は courseHeight (0.54)
  doors:   [{ wall: 'left', at: 1.5 }],                 // アーチ扉 (at = 壁に沿った中心の位置)
  torches: [{ wall: 'right', at: 2.1, height: 1.95 }],  // 松明 (光は背景に、炎は毎フレーム)
  objects: [                                            // 前後関係に参加する小物
    { type: 'column', cell: [2, 2] },
    { type: 'chest',  cell: [3, 0] },
    { type: 'barrel', cell: [5, 0] },
    { type: 'crate',  cell: [4, 5], s: 0.5 },           // 既定の寸法を上書きできる
  ],
  decor: [{ type: 'rubble', x: 0.35, y: 3.2, s: 0.14 }],   // 背景に焼き込む (キャラが後ろに回らない小さな物)
  stairs: [], dais: [], breach: null,
});
```

全項目と既定値は `docs/API_REFERENCE.md` §3。サンプル: `examples/room_viewer.html` (同じコードで3つの部屋を切り替える)。

## 2. 床・壁の描画

- 壁 (`buildWalls`): 石を段ごとに積み、長さをランダムに割り振って目地をずらす。最上段だけ高さを揺らして、上端をぎざぎざにする。
- 床 (`drawFloor`): 1マス = 1タイル。頂点を共有したまま少し揺らし、目地・ひび・角の欠け・壁際の陰 (点描) を描く。ひび・欠けの確率は `floor: { crack, chip }`。
- 手前の縁石 (`buildRim`): 床の断面を兼ねる2段積み。`breach: { x0, x1, h }` で一部を崩せる。
- 石ブロック1個は `drawStoneBox(ctx, {x0,x1,y0,y1,z0,z1}, { round, density, w, cracks })` (見える3面・角の欠け・点描・ひび)。新しい建築部品も、これを組み合わせて作れる (`src/authoring.js`)。

## 3. 扉・階段・柱

- 扉: `{ wall: 'left' | 'right', at, halfWidth = 0.64, spring = 1.3, ring = 0.3, depth = 0.3 }`。開口部 + 奥の暗がり + 側柱と迫石。壁面の座標系 (`wallFace`) で描くので、どちらの壁にも置ける。
- 階段: `{ wall, a0, a1, len, steps, depth, rise }` — 壁へ向かって上る。壁沿いの範囲 a0〜a1、壁からの奥行き len、段数・踏み板の奥行き・1段の高さ。
- 高台: `{ x0, x1, y0, y1, h }` — 壁際の2段の石の台。上に小物を置くときは小物に `z: h` を指定する。
- 柱: `objects` に `{ type: 'column', cell, h = 2.4, broken = false }`。`broken: true` で上端が斜めに折れた柱。

## 4. 小物の追加

小物の種類は `src/dungeon/props.js` の表 `PROP_TYPES` で決まります。新しい小物は1行足します。

```js
// 例: 壺 (まだ作っていない — 追加の手順の説明)
PROP_TYPES.pot = {
  label: '壺',
  draw: drawPot,                     // (ctx, p) → p.x, p.y (マス中心 + at), p.z と寸法でワールド座標に描く
  defaults: { r: 0.22, h: 0.5 },     // 既定の寸法 (配置データで上書きできる)
  height: p => p.h,                  // スプライトの高さ (前後関係の遮蔽判定にも使う)
};
```

- 描画関数は `drawStoneBox` / `drawStoneCylinder` / `drawGroundShadow` / `inkShape` / `stipplePoly` / `hatchPoly` などを組み合わせて書きます (`src/authoring.js`)。最初に `seed('pot' + p.x + '_' + p.y)` で乱数を固定すると、毎回同じ見た目になります。
- 床上の占有範囲 (前後関係用) は `propFootprint` に `case 'pot':` を足します (足さなければ ±0.3 の正方形)。
- ゲーム側から使うには、`objects` に `{ type: 'pot', cell: [i, j] }` と書くだけです。

## 5. オブジェクトの占有範囲

| 範囲 | 誰が使う | 内容 |
|---|---|---|
| 占有マス (`cell`) | **ゲーム** | 通れないマス。描画エンジンは使わない (統合デモでは game.js が `objects` の cell から作る) |
| 床上の占有範囲 (`propFootprint`) | 描画エンジン | 前後関係のソート。柱は台座の 0.84×0.84、樽は半径 × 1.14 の正方形など |
| 見た目の外接矩形 | 描画エンジン | 透視表示 (柱の陰のキャラ) の判定 |
| スプライトの箱 (`propBox`) | 描画エンジン | 小物を1枚の画像にする範囲 (影の分だけ床方向に余白) |

占有マスより見た目が小さい (柱の柱身は細いがマス全体を塞ぐ) ことがあります。これはゲームの規則の判断です。

## 6. 前後関係の扱い

- 小物・キャラ・飛んでいる矢は、床上の占有範囲どうしが x か y で離れていれば「奥 (小さい側) を先に描く」という条件で位相ソートします (`rendering/depth-sort.js`)。床上で重なる場合 (高台の上の宝箱など) は底面の高さ `z` が低い方を先に描きます。
- 背景 (壁・床・扉・縁石・decor) はいつも一番奥です。キャラが後ろに回り込める物は `decor` ではなく `objects` に置いてください。
- 高い小物の陰にキャラが隠れると、透視表示 (半透明の重ね描き) が出ます (`xray` オプション)。

## 7. 新しい部屋を追加する手順

1. 部屋データを書く (`id` を決める。同じ id なら同じ石組み)。
2. `examples/room_viewer.html` の `ROOMS` に加えて見た目を確認する (カメラ・前後関係・歩くキャラ)。
3. ゲーム側で、通れないマス・初期配置・敵の位置などの「規則のデータ」を別に持つ (統合デモの `SETUP`)。
4. `renderer.setRoom(データ)` で読み込む。部屋の大きさが変わってもカメラは自動で合わせます。

対応していないもの: L字型などの矩形以外の部屋・部屋の中の壁・複数の部屋のつながり・ランダム生成。
